# CodeAlpha_HangmanGame

A classic interactive Hangman game built in Python using Streamlit.

## 🚀 Features
- **Word Selection**: 5 predefined words selected at random.
- **Maximum 6 Attempts**: Visual ASCII art updates with every incorrect guess.
- **Category Hints**: Includes helpful clues for each word.
- **Session State**: Play multiple rounds smoothly with a game reset option.
